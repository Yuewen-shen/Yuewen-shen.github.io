# Yuewen Shen's Academic Homepage

Personal academic homepage of Yuewen Shen, Ph.D. candidate in Computer Science at the Muroran Institute of Technology.

Built with the [academic-homepage](https://github.com/luost26/academic-homepage) Jekyll template by Shitong Luo.

## Updating content

| What | Where |
| --- | --- |
| Name, bio, education, awards, links, photo | `_data/profile.yml` |
| Publications (one file per paper) | `_publications/<year>/*.md` |
| News | `_news/*.md` |
| Bold / linked author names | `_data/authors.yml` |
| Navigation bar | `_data/navigation.yml` |
